# 🚗 Car Rental – Car Rental Web and mobile Application

This project is a car rental application, consisting of both a **web** and **mobile** app. The core functionalities of the web app and mobile app are shared and rely on an integrated MySQL database.

---

## 🧠 Project Features

- **User Registration** and login
- **Car listings** and **car reservation** system
- **User profile management**
- **Admin panel** for managing cars and reservations
   **Car search and scanning** (e.g., vehicle registration scanning) (currently in progress)
- **Chatbot development** (currently in progress)

---

## 🔧 Technologies & Libraries Used

- **Frontend:** HTML, JavaScript, Dart, Flutter
- **Backend:** PHP, Django
- **Database:** MySQL, phpMyAdmin
- **Tools:** XAMPP, Firebase, Visual Studio Code

---

## 🚀 Installation & Usage

1. Clone the repository to your local environment
2. Set up the backend (PHP, XAMPP) with MySQL
3. Run the mobile application using Flutter (ensure Firebase integration for user authentication)
4. Start the Django server for the web interface
